## Catholic, Orthodox, or both

The site covers both Catholic and Orthodox saints, and many sources serve only one tradition. Each saint has a tradition type:

- **Catholic only.**
- **Orthodox only.**
- **Shared:** mostly saints of the undivided Church before 1054, and Western saints whom the Orthodox also honor. Use at least one strong source from each tradition. Record both feast days. Show how each Church remembers the saint when it differs.
- **Eastern Catholic:** saints of the Byzantine-rite Catholic Churches. Use Catholic sources and the sources of that Church.
- **Disputed:** honored by one Church and viewed critically by the other. Present both views fairly, with sources, without polemics. Set `venerated_in` only for the Church that honors the saint.

Each playbook has **Catholic sources** and **Orthodox sources** subsections where its region has both.

## Shape of a playbook

1. **Start here:** the three sources to try first, for each tradition that the region has.
2. **By era:** early Church (before about 600), medieval (600–1500), early modern (1500–1900), modern (after 1900). For each: the best sources, ranked.
3. **Access:** site search, URL patterns, how to get raw text, and technical traps.
4. **Language:** name forms, old spelling, transliteration, and the calendar.
5. **Rights.**
6. **Lessons log:** one dated line for each saint researched, written by the research agent: what worked, what failed, and what was missing. Keep the log short. When a lesson repeats, move it into the sections above.

Only write what has been checked. Mark unchecked leads as "unchecked".
